# 创作工作台界面约定

- 方向：可爱但可工作的「贴纸创作本」，不是营销落地页。
- 调色：纸粉 #fff5f8、莓果 #a63267、淡紫 #eee5ff、薄荷 #def2e9、墨梅 #382b45、描边 #e9d9e4。
- 字体：中文优先圆润的系统字体（幼圆 / 苹方 / 微软雅黑）；无需外部字体请求。
- 布局：左侧项目剧集导航；中间以节点画布串联故事、剧本与分镜；右侧可编辑内容与审核动作。
- 移动端提供列表模式，画布不是访问业务对象的唯一入口。
- 节点坐标、视角保存到后端；节点间依赖由业务事实确定，不允许连线伪造已批准关系。
- 错误、空态、载入和权限状态明确展示，禁止用假数据冒充后端结果。
- 所有关键按钮可键盘访问；尊重 reduced-motion；装饰不替代文字标签。

## 实施边界与验证

本批次新增身份、项目成员权限、内容编辑和画布布局 API，建立 React + TypeScript 前端。
保留现有文本工作流与迁移历史，新增 Alembic 版本；通过旧测试回归和新增权限/版本测试验证。
媒体生成、连续性审查、时间轴、渲染和预算等仍按原技术设计继续实施，不能以本批次完成替代总目标。
