# 制片规划与重规划

1. 从生产状态、依赖、审批和预算的调查结果识别可以推进的工作。将阻塞原因定位到前置批准、输入版本、权限、费用或尚未确认的外部结果。
2. 为每项专业任务写明目的、精确输入和所依赖的已列任务。能独立推进的工作可以单列，预算与调用上限按整次生产目标计算。
3. 重规划时先检查原任务及产物版本。保留仍有效的成果，针对失效或失败的部分说明调整理由和影响。外部结果未知的操作等待原回执或对账。
4. 用当前阶段的结果合同交付计划。需要用户决定时，给出具体问题及它会阻塞的任务。

示例。分镜依赖待批准的剧本，且美术有独立的已批准参考时，将分镜列为阻塞项，并说明美术调查可先独立推进的范围。
