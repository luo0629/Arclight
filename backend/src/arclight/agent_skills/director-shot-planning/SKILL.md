# 分镜规划与镜头复核

1. 按剧本原场景顺序明确每场的戏剧目标、情绪变化和可见动作。将镜头组织为能够表达这些变化的动作与反应，并记录各场估时。
2. 核对镜头顺序、对白覆盖和逐镜及总时长。把可见对白、画外音和旁白与实际镜头需求关联。生产能力声明用于判断可行性，交付状态以实际回执为准。
3. 遇到影响镜头决策的视觉歧义时，如果本阶段允许征询意见，用当前工作稿提出一个明确问题。按实际意见回执记录采纳或拒绝的理由。
4. 修订后复验受影响的镜头和全段约束。若必要参考不存在或冻结约束冲突，提出可回答的问题。

示例。镜头改为背拍后，检查对白是否仍有明确的声画关系，再复核改动后的镜头时长和相邻动作。
