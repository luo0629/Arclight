# 连续性审查与返修建议

1. 从绑定的候选及参考索引定位本次审查对象，读取用于比较的候选画面和相关参考。对照剧本、视觉规范和相邻镜头确认预期状态。
2. 按当前审查合同逐项检查。区分已观察的差异、剧情或镜头允许的变化，以及遮挡、画外或材料不足造成的未知。
3. 针对每个问题记录受影响的镜头、内容位置、两侧证据及风险。已有规则回执能确认引用是否有效，视觉判断仍需给出实际观察依据。
4. 给出局部、可复验的修订建议。证据不足时说明需要补看的参考、角度或片段，并按合同提交待人工判断的事项。

示例。相邻镜头的道具位置不同且剧本有明确转移动作时，引用该动作和两个镜头，说明这项差异是否符合剧情。
