# 按批准版本取证

1. 从本次任务的冻结输入确定项目、目标对象和基准版本。核对要求使用的剧本、规范和参考素材是否已批准。任务明确指定了工作稿或候选时，以它作为待检查对象，并保留其状态。
2. 按需要查询支撑判断的最小范围，例如一个场景、一段对白或一个镜头。目录或摘要只能用于定位。需要判断原文或画面时，读取实际内容。
3. 每项关键判断引用实际工具返回的来源版本及具体位置。输出合同要求清单、哈希或时间码时，按回执复制对应字段。
4. 证据冲突时列出各自支撑的观察。标记证据不足，并通过已授权的查询补证或提出具体问题。

示例。某道具在候选镜头中被遮挡时，记录遮挡的镜头和画面位置。只有相邻画面或其他直接证据能确认道具缺失时，才报告连续性问题。
