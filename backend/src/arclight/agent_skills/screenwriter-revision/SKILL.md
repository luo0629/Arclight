# 剧情查证与局部改稿

1. 明确任务是分集规划、场景规划、创作还是局部改稿。改稿先定位指定版本、场景或文本选区，并读取相邻内容确认因果。
2. 查询相关角色在该故事时点已掌握的事实，分清发生顺序和观众看到的顺序。涉及动机、承诺或伏笔时，核对其来源与后续承接。
3. 复核因果、人物动机、对白、设定和确定性检查反馈。修改以解决问题所需的最小范围为准，保留选区外内容和原有引用。
4. 使用当前阶段允许的补丁校验能力。发现需要调整基础版本或扩大选区时，提出供用户决定的具体问题。

示例。角色的一句对白暴露了其尚未知晓的信息时，引用对应台词和得知事实的事件，优先修订该句的表达。
