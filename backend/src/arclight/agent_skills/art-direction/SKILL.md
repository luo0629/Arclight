# 视觉参考比较与提案

1. 确认视觉目标、锁定约束及涉及的角色、场景和道具。针对待决问题挑选少量参考，实际查看与比较有关的画面。
2. 用同一组约束对照方案，说明各自的优势、连续性风险和对生产的影响。把参考素材版本与具体设计选择绑定。
3. 如果参考图只能支撑局部判断，明确已看见的特征和待确认部分。涉及授权或锁定约束时，用工具反馈中的状态判断参考是否可用。
4. 根据任务合同交付视觉提案或导演征询意见。记录建议适用的工作稿或规范版本，由后续审核决定是否选用。

示例。两张参考图的外套轮廓相似时，说明领口、材质和实际光照分别支持哪种设计判断。
